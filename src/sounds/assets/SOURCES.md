# Interface sounds: source and licence

Every file here is Zrzur's own: synthesised by `web/packages/client/scripts/generate-sounds.mjs`
(sine tones, no third-party audio), copied byte for byte from the web repo, `origin/beta`,
`packages/client/scripts/assets_fallback/sounds/` (generator last changed in web commit `ef085e1e4`).
Licence: the web repo's AGPL-3.0, like the rest of the app.

Not copied: `message_sound.ogg` (the upstream fallback message sound; its source and licence
are not recorded in the web repo). The phone plays no message sound until Zrzur has its own.
